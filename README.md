# «Местный сад» — версия для сравнения

Сохранённый дизайн сайта до премиального редизайна 6 октября 2026 года.

**Открыть сайт:** https://gennadijvaliev02-design.github.io/sad/

Исходный index.html и assets находятся в корне репозитория. GitHub Pages публикует их из ветки main. Это самостоятельная статическая копия: backend, базы заявок, .env и ключи доступа не включены. Отправка формы отключена; её оформление и остальная клиентская интерактивность сохранены. Телефон и ссылки WhatsApp — из исходного сайта.

Эта версия сохраняется для сравнения с действующим сайтом http://109.172.8.196/ и не получает его последующие изменения дизайна автоматически.
