# Местный сад — резервная копия сайта

Сохранена исходная опубликованная версия http://109.172.8.196/ **до премиального редизайна 6 октября 2026 года**.

## Бэкап

- [Архив сайта](backups/2026-10-06-before-premium/production-before.tar.gz)
- [SHA-256 архива](backups/2026-10-06-before-premium/SHA256SUMS)
- [Контрольные суммы исходных файлов](backups/2026-10-06-before-premium/manifest.json)

Архив содержит index.html, styles.css, script.js, SOURCES.md и каталог assets с изображениями и видео. Это статическая часть сайта. Backend, базы заявок, .env и ключи доступа в архив не включены.

Для просмотра копии распакуйте архив в отдельную папку и запустите там локальный HTTP-сервер. Для полного сценария заявки нужен прежний серверный обработчик /api/order; он в этот бэкап статических файлов не входит.

Текущий дизайн сайта в этот архив не добавлялся: здесь хранится именно версия, сохранённая перед изменениями.
